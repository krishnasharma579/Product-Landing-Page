# Product Landing Page

A responsive and modern product landing page built using **HTML**, **CSS**, and **JavaScript**. This project was created to strengthen front-end development fundamentals, including responsive layouts, navigation design, and basic JavaScript interactions.

## Preview

The landing page presents an organic product with a clean user interface, responsive navigation, and a prominent call-to-action section.

## Features

* Responsive landing page layout
* Modern navigation bar
* Mobile-friendly hamburger menu
* Product hero section
* Call-to-action button
* Clean and minimal UI
* Responsive design for different screen sizes

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Getting Started

### Clone the repository

```bash
git clone https://github.com/krishnasharma579/Product-Landing-Page.git
```

### Navigate to the project folder

```bash
cd Product-Landing-Page
```

### Run the project

Open `index.html` in your preferred web browser.
